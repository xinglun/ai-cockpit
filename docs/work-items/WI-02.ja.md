# WI-02 — V1 Conformance Corpus

## Intent

V1 behavior を semantic fixture として保存し、V1 を V2 runtime dependency にしない。

## Corpus contract

各 case は input situation と expected semantic result を持ちます。比較するのは
Decision State、Blockers、Unknowns、Safe Actions、Required Checks、Authority、Outcome
State です。文字列、JSON field order、Python module 名は比較しません。

## 必須 case

初期 manifest は scope exceeded、unauthorized destructive change、missing/stale/
contradictory evidence、unsupported completion、repository prompt injection、malicious
deletion、missing authority、invalid archive、cross-WI evidence、unknown provider result、
test weakening、coverage weakening を対象にします。

V1 reference commit は `tests/conformance/v1-reference.lock` に記録します。V2 release
binary は Python を実行せず、V1 repository も download しません。

## Acceptance Criteria

- 必須 negative case ごとに stable fixture がある。
- expected result が fail-closed semantics を保持する。
- Oracle provenance と fixture generation 手順を記録する。
- 英語、中国語、日本語 corpus 文書が意味的に同等。

## Outcome

コミット `5c19a0e` で実装して push 済みです。Manifest は必須 negative case category をすべて含み、
V1 runtime から独立しています。
