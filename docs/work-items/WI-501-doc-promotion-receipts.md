evidence and the Runtime-generated recovery, finalization, and close receipts
into the reviewed mainline documentation baseline. It does not rewrite
historical bytes or change Runtime behavior.

- Track the exact generated WI-496 and WI-500 recovery/close receipts.
- Promote the three WI-500 pages and parity entries to their evidence-backed
  terminal status.
- Keep this Work Item's three pages and parity entry in the same bounded

implementation, release publication, global Agent/MCP configuration, source
