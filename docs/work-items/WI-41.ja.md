# WI-41 — Reference source parity と reader entry

## 意図と目標

V1 runtime state を取り込まずに `spirex-ds-dev/ai-cockpit-template` と比較し、
Rust project の公開入口を初めて採用する読者にも理解できる形にします。

## Scope

- reference tree、user journey、capability index、release/upgrade boundary を比較する。
- 三言語の parity matrix と明示的な follow-up boundary を追加する。
- root README の三言語を相互リンクし、実行可能な 30 秒 attach/status route を示す。
- `cockpit.toml` は TOML のまま保持し、V1 を install しない boundary を維持する。

## 受入れ

1. parity page が reference と Rust の commit を記録し、implemented、partial、
   intentionally absent、follow-up を区別する。
2. English、中文、日本語の root README が相互にリンクし、具体的な attach/status
   first step を示す。
3. 現在の code、test、documentation evidence のない capability claim を追加しない。
4. V1 file、runtime、global Agent setting、repository schema をコピーしない。

## Evidence

installed Runtime verification receipt を参照します。

## 結果
