# WI-01 — Repository Protocol v1

## Intent

Rust adapter を実装する前に repository-owned storage protocol を定義する。

## Scope

- `.ai/` layout と artifact identity。
- canonical digest と timestamp ルール。
- Contract envelope と decision semantics。
- Protocol compatibility と migration boundary。
- machine-readable v1 schema と三言語文書。

## Out of Scope

- filesystem 実装。
- runtime serialization code。
- Protocol v2 migration。

## Sources

- V2 execution specification。
- WI-00 product boundary。
- V1 の evidence/lifecycle semantics（参照のみ）。

## Acceptance Criteria

- すべての `.ai/` artifact に owner と identity rule がある。
- Runtime と protocol version が独立している。
- compatibility inspection が historical evidence を書き換えない。
- 未対応 protocol major は fail closed。
- 英語、中国語、日本語の仕様が意味的に同等。

## Verification

- standards-compliant validator で JSON schema を parse する。
- conformance test に valid/invalid protocol example を追加する。
- `git diff --check` が通る。

## Outcome

コミット `5c19a0e` で実装して push 済みです。Protocol JSON と corpus JSON の parse に成功し、
V1 runtime code は copy していません。
