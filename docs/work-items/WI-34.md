# WI-34 — Installable Release and Homebrew Distribution Readiness

## Intent and Goal

Turn the WI-24 build evidence into a deterministic, testable installation
contract for GitHub Release archives, Homebrew, manual installation, and a
tag-pinned Cargo Git fallback without claiming a public release.

## Scope and Out of Scope

In scope: strict release manifest and version binding; stable archive layout;
deterministic macOS ARM64/Intel Formula generation; source, archive, checksum,
SBOM, and provenance coherence; staged install/uninstall/upgrade tests; a
cross-repository handoff; least-privilege release workflow design; and English,
Simplified Chinese, and Japanese installation documentation.

Out of scope: changing `cockpit.toml` to JSON; V1 installation; Linuxbrew
Formula support; crates.io publication; creating `xinglun/homebrew-tap`;
commit/push; hosted workflow dispatch; tag or GitHub Release creation; tap PR
creation/merge; repository attach; and any claim that installation is public.

## Acceptance Criteria

1. Tag, workspace, package, binary, commit, lockfile, archive, and manifest
   identities are checked and mismatches fail closed.
2. The five target archives have one stable layout and one canonical manifest
   plus checksum set.
3. Formula generation is strict, deterministic, and complete for macOS ARM64
   and Intel, with exact HTTPS URLs and SHA-256 values.
4. Manual dispatch cannot publish; tag publication is gated by all source,
   artifact, manifest, smoke, SBOM, provenance, and release checks.
5. Cross-repository Formula delivery is an identity-bound PR handoff and never
   a default-token or direct-default-branch push.
6. Hosted fixture jobs are fully defined for Homebrew install/test/uninstall on
   current ARM64 and Intel runners without requiring a public Release; running
   them and recording hosted receipts belongs to WI-35.
7. Local archive/Cargo Git fixtures and workflow policy tests prove the
   fallbacks are configuration-complete; hosted Linux/Windows receipts belong
   to WI-35.
8. Three-language documentation covers install, verify, upgrade, uninstall,
   rollback, manual archives, Cargo Git, MCP, and install-versus-attach.
9. No `curl | sh` primary installer, Linuxbrew claim, crates.io claim, mutable
   tag reuse, or unverified public-install claim is introduced.
10. This development repository remains without `.ai/`.
