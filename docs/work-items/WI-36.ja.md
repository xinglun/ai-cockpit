# WI-36 — Release Gate Correction: Tag Identity と Runner Lifecycle

## Intent and Goal

WI-35 の release 前 acceptance で確定した二つの blocker を修正し、新しい candidate を immutable tag と現在サポートされる hosted runner に正しく bind できる状態にします。この Work Item は Release を publish せず、Homebrew tap も変更しません。

## Scope と Out of Scope

Scope は、remote tag と release commit の比較前に annotated tag を peel すること、annotated-tag regression fixture の追加、ARM64 macOS build identity の deprecated `macos-14` から supported な固定 runner への移行、manifest mapping・fixture・test・design/plan・release policy の同期、local gate の再実行、review 可能な candidate diff の準備です。commit/push は authorization 済みの integration handoff であり、local corrective step には含めません。

Out of Scope は tag creation、GitHub Release publication、`xinglun/homebrew-tap` の作成・変更、hosted dispatch、public installation、runtime governance semantics、V1 installation、`.ai/` creation、`cockpit.toml` の JSON 化です。

## Sources と Unknowns

Sources は WI-35 pre-release acceptance、`.github/workflows/release.yml`、`cockpit-release` manifest validator/test、isolated annotated-tag reproduction、GitHub official runner image availability、WI-35 design/plan/install contract です。

annotated tag の unpeeled object SHA と peeled commit SHA が異なること、現在の publish job が unpeeled value を比較していること、`macos-14` が GitHub の deprecation window に入っていること、Rust/release-contract/V1 Oracle/archive/Cargo Git の local check が green であること、current candidate tree が clean でないことは Known です。

hosted job result、final tag/provider Release identity、provenance attestation、tap permission、tap PR identity、real adopter installation receipt は WI-35 が持つ Unknowns です。

## Acceptance Criteria

1. publish job は remote tag の peeled commit（`refs/tags/<tag>^{}` または同等の検証済み lookup）を manifest と workflow commit と比較し、immutable check を弱めずに規定した tag form を扱う。
2. regression test が annotated tag object SHA を commit identity として拒否し、peeled commit を受け入れる。lightweight tag は明示的に cover するか拒否する。
3. five-target manifest、workflow matrix、fixture、test、docs が supported な固定 ARM64 macOS runner を使い、`macos-14` build identity を残さない。
4. 修正後の tree で cargo fmt、warnings-denied Clippy、workspace test 二回、Windows cross-target check、release workflow policy、YAML/Bash/Action pin check、release-package test、V1 Oracle、archive inspection、Cargo Git install がすべて pass する。
5. 修正後の candidate diff は記録した base から review できます。no-commit constraint により共有 worktree は未 commit のままとし、integration commit と push は authorization 済みの WI-35/integration handoff action とします。
6. この Work Item は tag、provider Release、tap、PR、hosted dispatch、public installation、V1 file、`.ai/`、configuration migration を作成しない。

## Required Evidence

annotated-tag fixture output、release workflow diff/policy result、runner availability source、updated manifest/fixture/test result、full local quality log、V1 Oracle output、review 可能な diff/tree status、two independent review record、WI-35 への explicit handoff が必要です。local result で hosted/public-release evidence を代替しません。
