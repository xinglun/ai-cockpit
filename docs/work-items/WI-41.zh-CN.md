# WI-41 — 参考源对齐与读者入口

## 意图与目标

在不导入 V1 runtime state 的前提下，对照
`spirex-ds-dev/ai-cockpit-template`，并让 Rust 项目的公开入口适合第一次采用的读者。

## 范围

- 比较参考源目录、用户阅读路线、功能索引以及 release/upgrade 边界；
- 增加三语参考源对齐矩阵和明确的后续边界；
- 让根 README 的三种语言互相链接，并提供可运行的 30 秒 attach/status 路线；
- 保留 `cockpit.toml` 为 TOML，并保留明确的 V1 不安装边界。

## 验收

1. 对齐页记录参考源和 Rust commit，并区分已实现、部分完成、有意不实现和后续能力。
2. 英文、中文、日文根 README 互相链接，并提供具体 attach/status 第一步。
3. 没有脱离当前代码、测试或文档证据新增能力声明。
4. 不复制 V1 文件、runtime、全局 Agent 设置或 repository schema。

## 证据

参见 `docs/reference/reference-parity*`、三个根 README 和本 Work Item 的已安装
Runtime verification receipt。

## 结果

参考源对齐页和读者入口完成并通过验证后，本 Work Item 完成。升级行为和内部文档
清理分别由 WI-43 与 WI-42 负责。
