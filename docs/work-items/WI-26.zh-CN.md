# WI-26 — 确定性的 MCP 安全测试夹具

## 意图与目标

消除 WI-25 再验收中暴露的临时目录竞态，确保 Rust 并行执行测试时 workspace
质量门禁保持确定性。

## 范围与非范围

范围：MCP 安全测试的仓库路径生成器及其验证证据。

非范围：生产 MCP 行为、Repository Protocol 行为、V1 Oracle 集成、自治理、正式
发布和其他无关测试夹具。

## 来源与未知项

来源：第一次再验收运行 `cargo test --workspace` 时在
`crates/cockpit-mcp/tests/security.rs:16` 出现的 `AlreadyExists`，以及随后通过的
隔离复跑。

已知：同一进程内两个测试可能取得相同的 PID 和纳秒时间戳，使 `create_dir` 失败。

本次限定修复范围内没有未知项。

## 验收标准

1. 并行 MCP 安全测试不能选择同一个临时仓库路径。
2. 不修改生产 crate 行为。
3. MCP 安全测试高频重复运行和两次完整 workspace 测试均通过。
4. Clippy、格式和 diff 检查通过。

## 必需证据

- RED：第一次完整再验收中的 `AlreadyExists` 失败。
- 重复运行 MCP security 测试。
- 两次 `cargo test --workspace`。
- Clippy、fmt 和 diff 检查。
