# WI-05 — Git リポジトリスナップショット

## 意図

status、diff、tree、依存 fingerprint を含む不変スナップショットを一度だけ作成する。

## 受入れ

スナップショットが決定的なパス、digest、ファイル/ハッシュ数、bounded な Git 呼び出しを報告する。

## 証拠

cockpit-git repository テスト；inspect telemetry

## 結果

状態：**Implemented**。snapshot テストが決定的 digest、bounded Git call、依存 path が重複する場合の一度だけの hash を検証する。
