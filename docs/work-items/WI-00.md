# WI-00 — V2 Architecture and Non-goals

## Intent

Establish a new Rust product boundary without installing or translating the V1
runtime.

## Scope

- Product identity and non-goals.
- Northbound MCP/CLI and southbound Repository Protocol boundaries.
- Runtime/Repository context separation.
- Versioning, evidence, human-control, and self-governance rules.
- English, Chinese, and Japanese documentation equivalents.

## Out of Scope

- Rust implementation code.
- V1 installer or runtime compatibility.
- Provider identity, production isolation, or compliance certification.

## Sources

- User-provided V2 development execution specification.
- V1 reference repository at `spirex-ds-dev/ai-cockpit-template`, pinned during
  conformance work as an evidence reference only.

## Acceptance Criteria

1. A reader can distinguish V2 from a V1 upgrade or port.
2. The runtime/repository boundary is explicit.
3. Runtime and protocol versioning are independent.
4. The bootstrap process does not install V1.
5. The three language documentation sets express the same boundaries.

## Verification

- Read all linked documents in English, Chinese, and Japanese.
- Confirm no V1 runtime files or installer files are present.
- Confirm the worktree contains only documentation changes for this WI.
