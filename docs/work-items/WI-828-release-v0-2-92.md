# WI-828 — governed v0.2.92 release

## Intent and boundary

WI-828 aligns the workspace and current release projections to v0.2.92 and
publishes the reviewed main revision as an immutable Release. Candidate and
public acceptance must consume identity-bound artifacts in isolated roots.

Historical Work Item migration, changes to v0.2.91, unrelated performance work,
and user-global configuration are outside this Work Item.

## Acceptance

- Cargo metadata, lockfile, current release documentation, and reference
  comparison metadata identify v0.2.92 consistently.
- Hosted source verification, build, candidate installation, and N-1 upgrade
  pass with retained identity-bound receipts.
- The public v0.2.92 artifact passes fresh installation, N-1 upgrade, version
  consistency, and cleanup checks.
- Failure recovery reuses valid phases without rebuilding or republishing, and
  finalization, archive, close, and documentation promotion are confirmed.

## Verification

- `bash tests/release/version_consistency.sh --repo <repo>`
- `python3 tests/docs/reference_comparison_metadata_test.py`
- `bash tests/docs/documentation_acceptance.sh`
- `bash tests/docs/parity_status_check.sh <repo>`
- `cargo fmt --all --check`
- `cargo test --locked --workspace --all-targets`
- Hosted release preflight, candidate acceptance, public artifact acceptance,
  N-1 upgrade, and close-only recovery.

## Evidence policy

Release tags, provider assets, manifests, and public acceptance receipts remain
immutable external facts. Runtime Contract, verification, archive,
finalization, and close records are generated by the installed Runtime and are
never replaced by a local build or a moving branch.
