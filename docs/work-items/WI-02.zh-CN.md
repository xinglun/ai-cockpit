# WI-02 — V1 Conformance Corpus

## Intent

把 V1 行为记录为语义 fixture，但不让 V1 成为 V2 runtime dependency。

## Corpus contract

每个 case 包含输入情形和 expected semantic result。结果比较 Decision State、Blockers、
Unknowns、Safe Actions、Required Checks、Authority 和 Outcome State，不比较字符串、
JSON field 顺序或 Python module 名。

## 必需 case

初始 manifest 覆盖 scope exceeded、未授权 destructive change、missing/stale/contradictory
evidence、unsupported completion、repository prompt injection、malicious deletion、
missing authority、invalid archive、cross-WI evidence、unknown provider result、test
weakening 和 coverage weakening。

V1 reference commit 记录在 `tests/conformance/v1-reference.lock`。V2 release binary
不会调用 Python，也不会下载 V1 repository。

## Acceptance Criteria

- 每个要求的 negative case 有稳定 fixture。
- expected result 保持 fail-closed 语义。
- 记录 Oracle 来源和 fixture 生成说明。
- 英文、中文、日文 corpus 文档语义等价。
