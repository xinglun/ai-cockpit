# WI-863 — 只读 CLI 诊断的一致 JSON 选项

为顶层 `inspect`、`status` 和 `doctor` 命令补齐文档化的 `--json` 选项。
该选项选择稳定的机器可读投影，不改变事实、退出码或仓库范围。
