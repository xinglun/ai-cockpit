# WI-00 — V2 架构与非目标

## Intent

建立全新的 Rust 产品边界，不安装或翻译 V1 runtime。

## Scope

- 产品身份与非目标。
- Northbound MCP/CLI 和 Southbound Repository Protocol 边界。
- Runtime/Repository context 分离。
- 版本、证据、人类控制和自治理规则。
- 英文、中文、日文文档等价版本。

## Out of Scope

- Rust 实现代码。
- V1 installer 或 runtime compatibility。
- Provider identity、production isolation 或 compliance certification。

## Sources

- 用户提供的 V2 开发执行指示。
- `spirex-ds-dev/ai-cockpit-template` V1 reference；只作为证据参考。

## Acceptance Criteria

1. 读者可以区分 V2 与 V1 升级/移植。
2. Runtime/repository 边界明确。
3. Runtime 与 protocol version 独立。
4. Bootstrap 过程不安装 V1。
5. 三种语言表达相同边界。

## Verification

- 阅读三种语言的全部关联文档。
- 确认没有 V1 runtime 或 installer 文件。
- 确认本 WI 只产生文档变化。

## Outcome

等待实现与审查。
