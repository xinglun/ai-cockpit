# WI-07 — Living Project Profile

## 意図

repository 単位の profile を永続化し、後続 contract のために digest を保持する。

## 受入れ

Attach は profile v1 を作成し、profile 変更は提案に留まり、gate を黙って変更しない。

## 証拠

attach/profile digest テスト

## 結果

状態：**Implemented**。attach/profile テストが profile v1、digest 履歴、確認、profile-v2 の decision evidence を検証する。
