# WI-24 — リリースと配布

## 意図

multi-platform build、checksum、SBOM、signature、provenance evidence を定義する。

## 受入れ

release automation は evidence を公開し、core self-attestation を主張しない。

## 証拠

release workflow と文書

## 結果

状態：**Implemented、protected release execution pending**。matrix は macOS arm64/x86_64、Linux arm64/x86_64、Windows x86_64 を対象とし、checksum、SPDX SBOM、provenance attestation、optional cosign signing を定義済み。最終 receipt には protected CI credential と release tag が必要。
