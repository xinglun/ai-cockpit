# WI-36 — 发布门禁纠正：Tag 身份与 Runner 生命周期

## 意图与目标

修复 WI-35 发布前验收发现的两个确定性阻塞，使新的候选能够绑定到不可变 tag 和当前受支持的 hosted runner。
本 Work Item 不发布 Release，也不修改 Homebrew tap。

## 范围与明确不属于范围

范围内：在比较远端 tag 与 release commit 时剥离 annotated tag；增加 annotated-tag 回归 fixture；将 ARM64
macOS 构建身份从已进入退役周期的 `macos-14` 迁移到受支持的固定 runner；同步 manifest 映射、fixtures、测试、design/plan
文本和 release policy；重新运行本地门禁；准备可审查的 candidate diff。commit/push 属于获得授权后的 integration 交接，不属于本地纠正步骤。

范围外：创建 tag、发布 GitHub Release、创建或修改 `xinglun/homebrew-tap`、hosted dispatch、公开安装、runtime governance
语义、安装 V1、创建 `.ai/`，以及将 `cockpit.toml` 改为 JSON。

## 来源与未知项

来源：WI-35 发布前验收、`.github/workflows/release.yml`、`cockpit-release` manifest validator 与测试、隔离的 annotated-tag
复现、GitHub 官方 runner image 可用性资料，以及 WI-35 design、plan 和安装契约。

已知：annotated tag 的未剥离 object SHA 与 peeled commit SHA 不同；当前 publish job 比较了未剥离值；`macos-14` 已进入 GitHub
退役周期；Rust、release contract、V1 Oracle、archive 和 Cargo Git 本地检查均为绿色；当前 candidate tree 不干净。

仍由 WI-35 负责的未知项：hosted job 结果、最终 tag 与 provider Release identity、provenance attestation、tap 权限、tap PR identity
以及真实 adopter 安装回执。

## 验收标准

1. publish job 比较远端 tag 的 peeled commit（`refs/tags/<tag>^{}` 或等价的经验证查询）与 manifest/workflow commit，并在不削弱不可变检查的前提下接受文档规定的 tag 形式。
2. 回归测试证明 annotated tag object SHA 不能作为 commit identity，而 peeled commit 可以；lightweight tag 必须明确覆盖或明确拒绝。
3. 五目标 manifest、workflow matrix、fixtures、测试和文档都使用当前受支持的固定 ARM64 macOS runner；不再残留 `macos-14` 构建身份。
4. 从修正后的 tree 运行 cargo fmt、warnings-denied Clippy、完整 workspace 测试两次、Windows cross-target check、release workflow policy、YAML/Bash/Action pin 检查、release-package 测试、V1 Oracle、archive inspection 和 Cargo Git 安装，全部通过。
5. 修正后的 candidate diff 可基于记录的 base 审查。共享 worktree 按照 no-commit 约束保持未提交；创建 integration commit 和 push 属于获得授权后的 WI-35/integration 交接动作。
6. 本 Work Item 不创建 tag、provider Release、tap、PR、hosted dispatch、公开安装、V1 文件、`.ai/` 或配置格式迁移。

## 所需证据

Annotated-tag fixture 输出、release workflow diff 与 policy 结果、runner 可用性来源、更新后的 manifest/fixture/test 结果、完整本地质量日志、V1 Oracle 输出、可审查 diff/tree 状态、两位独立 reviewer 记录，以及交接到 WI-35 的明确记录。不能用本地结果代替 hosted/public-release 证据。
