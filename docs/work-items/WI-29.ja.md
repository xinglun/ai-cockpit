# WI-29 — Collision-Free Parallel Test Repositories

## 意図と目標

WI-28 full gate で見つかった race を修正する。Rust が test を並列実行しても、
複数 test が同じ temporary repository を選択してはならない。

## Scope と Out of Scope

Scope は wall-clock nanoseconds だけを使う全 integration-test helper と repeated/full
workspace regression。Out of Scope は production temporary-file behavior、Runtime
repository semantics、WI-28 governance detection、external CI、release。

## Sources と Unknowns

Source: `cargo test --workspace --quiet` が `attach.rs` で失敗した。2 つの
`git init` が同じ `cockpit-attach-1787276227293393000` を選び、Git hook template
の existing error 後に attach が invalid repository を観測した。

Known: 複数 test file が PID/sequence のない timestamp pattern を繰り返す。WI-26
は MCP security fixture のみ修正した。この test-only boundary に Unknown はない。

## Acceptance Criteria

1. 全 vulnerable helper は PID、nanosecond、process-local atomic sequence を含む。
2. WI-29 は production source を変更しない。
3. Repeated attach と affected integration tests は deterministic である。
4. WI-28 再開前に workspace 2 runs と全 static gates が通る。

## Required Evidence

Recorded RED、repeated focused tests、workspace 2 runs、Clippy、fmt、diff、workflow、
multilingual checks。
