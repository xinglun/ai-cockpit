# WI-42 — 文档治理与 Agent 使用路线

## 意图与目标

让自我治理和公开 `v0.1.1` release 之后的文档保持真实。读者路线必须说明已安装的共享
Runtime 做什么、如何 attach repository、如何显式连接 Agent；内部实现历史不得被展示为当前
产品状态。

## 范围

- 从公共文档入口和 release architecture 中删除过期进度、未自我治理和 WI-35 待发布声明；
- 保持英文、中文和日文 README 与 Work Item 路线一致；
- 增加 repository-local `.ai/README.md` 和 `.ai/glossary.md`，作为 Agent 使用与术语入口；
- 在 repository-owned `AGENTS.md` 中增加简明使用说明，不修改全局 Agent 或 MCP 配置；
- 历史 Work Item 继续保留在 Git 中作为审计记录，不作为采用者操作指南。

## 验收

1. 公共文档不再声称本仓库未 attach、Runtime 不能治理自身或 `v0.1.1` 仍待发布。
2. 根 README 与文档 README 的语言链接互相可达，路线按读者目标而不是实现时间组织。
3. `.ai/README.md` 给出显式 `--repo` 命令、生命周期顺序、adapter 边界和证据纪律，不能伪造治理结果。
4. `.ai/glossary.md` 区分共享 Runtime、Repository Context、Adapter、Work Item、evidence 和 migration。
5. `AGENTS.md` 指向 repository-local 路线，不改变 managed adapter section 或全局配置。
6. 三个 `docs/work-items/README*` 都说明已安装 Runtime 的自我治理，并不使用 V1 `make ai-*` 流程。

## 证据

验证包括文档扫描、Agent doctor ownership、链接检查和本 Work Item 的已安装 Runtime verification receipt。

## 结果

公共文档和 Agent route 完成更新。Runtime migration 行为由 WI-43 独立负责，不能只从文档推断。
