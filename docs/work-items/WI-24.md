# WI-24 — Release and Distribution

## Intent

Define multi-platform build, checksum, SBOM, signature, and provenance evidence.

## Acceptance

Release automation must publish evidence without claiming core self-attestation.

## Evidence

release workflow and docs

## Outcome

Status: **Implemented with protected release execution pending**. The matrix covers macOS arm64/x86_64, Linux arm64/x86_64, and Windows x86_64; checksums, SPDX SBOM, provenance attestation, and optional cosign signing are defined. Protected CI credentials and a release tag are required to produce final receipts.
