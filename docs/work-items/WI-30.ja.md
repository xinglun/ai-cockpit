# WI-30 — Self-Governance Cutover Readiness

## 意図と目標

Markdown Bootstrap governance から、この repository 自身の Rust AI Cockpit
runtime による governance への truthful/fail-closed な移行を準備する。

## Scope と Out of Scope

Scope は cutover precondition、exact binary identity、明示的な attach/profile human
decision、thin `.ai/` state verification、doctor/status check、最初の governed
lifecycle exercise。

Out of Scope は V1 installation、runtime/schema copy、dirty worktree への silent
attach、human authority のない commit/push、hosted CI、tag、release、無関係な feature。

## Sources と Unknowns

Sources は AI Cockpit が未 install という user clarification、product specification
section 3–5、`docs/work-items/README.md`、Repository Protocol v1、実装済み Rust
attach/status/doctor/lifecycle command。

Known: `.ai/` は存在せず、現在の WI は manual Bootstrap record である。Rust attach
は protocol facts だけを書く設計である。

Unknown: cutover 元となる integrated revision と、commit/integration、repository
attach、profile confirmation に対する human authority。これらは明示的 stop condition。

## Acceptance Criteria

1. Attach 前に WI-25〜WI-29 が review/integration 済みの clean identified revision
   になっている。
2. Exact runtime binary version と SHA-256 digest を記録する。
3. Attach と profile confirmation の前に明示的 human approval がある。
4. Attach は `.ai/` facts のみ作成し runtime implementation を copy しない。
5. Status/doctor が protocol compatibility と repository runtime code 不在を確認する。
6. Bootstrap retirement 前に first governed lifecycle exercise が central preflight と
   human close path を証明する。
7. 全 cutover evidence が Green になった後だけ Bootstrap documentation を変更する。

## Required Evidence

status/doctor receipts、human profile decision、first governed lifecycle receipts。
