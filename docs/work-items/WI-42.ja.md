# WI-42 — Documentation governance と Agent route

## 意図と目標

self-governance と public `v0.1.1` release 後の documentation を current fact に合わせます。
reader route は installed shared Runtime の役割、repository の attach、Agent の明示的な接続を
説明し、internal implementation history を current product status として表示しません。

## Scope

- public documentation home と release architecture から stale progress、pre-self-governance、
  WI-35 pending claim を削除する。
- English、中文、日本語の README と Work Item route を揃える。
- Agent-facing usage と vocabulary の入口として repository-local `.ai/README.md` と `.ai/glossary.md`
  を追加する。
- repository-owned `AGENTS.md` に短い usage guidance を加えるが、global Agent/MCP configuration は変更しない。
- historical Work Item は Git の audit record として残し、adopter guidance にはしない。

## 受入れ

1. public documentation home が未 attach、Runtime が self-governance できない、または `v0.1.1` が
   pending だと述べない。
2. root/documentation README の language link は相互に到達でき、route は chronology ではなく reader goal で構成する。
3. `.ai/README.md` が明示的な `--repo` command、lifecycle order、adapter boundary、evidence discipline を示し、
   governance result を捏造しない。
4. `.ai/glossary.md` が shared Runtime、Repository Context、Adapter、Work Item、evidence、migration を区別する。
5. `AGENTS.md` が repository-local route を指し、managed adapter section と global configuration を変更しない。
6. 三つの `docs/work-items/README*` が installed-runtime self-governance と V1 `make ai-*` 非使用を説明する。

## Evidence

documentation scan、Agent doctor ownership、link check、本 Work Item の installed Runtime verification receipt を用います。

## 結果

public docs と Agent route が current になった時点で完了します。Runtime migration behavior は WI-43 の別 scope です。
