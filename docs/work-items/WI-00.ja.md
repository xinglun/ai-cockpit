# WI-00 — V2 アーキテクチャと非目標

## Intent

V1 runtime を install または翻訳せず、新しい Rust 製品境界を確立する。

## Scope

- 製品 identity と non-goals。
- Northbound MCP/CLI と Southbound Repository Protocol の境界。
- Runtime/Repository context の分離。
- version、evidence、human control、自律 governance のルール。
- 英語、中国語、日本語の同等な文書。

## Out of Scope

- Rust 実装コード。
- V1 installer または runtime compatibility。
- Provider identity、production isolation、compliance certification。

## Sources

- ユーザーが提供した V2 開発実行指示。
- `spirex-ds-dev/ai-cockpit-template` の V1 reference。evidence 参照だけに使う。

## Acceptance Criteria

1. V2 が V1 upgrade/port ではないことを説明できる。
2. Runtime/repository 境界が明示されている。
3. Runtime と protocol version が独立している。
4. Bootstrap が V1 を install しない。
5. 三言語が同じ境界を表現する。

## Verification

- 英語、中国語、日本語の関連文書を読む。
- V1 runtime と installer が存在しないことを確認する。
- 本 WI が文書変更だけであることを確認する。
