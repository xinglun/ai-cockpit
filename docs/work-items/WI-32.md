# WI-32 — Fail-Closed Evidence Reuse Planner

## Intent and Goal

Replace caller-declared verification skips with composite receipt validation,
dependency-aware planning, and observable bounded execution.

## Scope and Out of Scope

In scope: content/diff/environment composite identity, content-addressed passed
receipts, Fresh/Stale/Unknown classification, actual command identity,
protected-node enforcement, dependency invalidation, and execution metrics.

Out of scope: receipt-file persistence, profile-driven CLI/MCP reuse,
repository attach, commit/push, hosted CI, release signing, and publication.

## Sources and Unknowns

Sources: the user-authorized WI-32 design; execution specification section 14;
the current Rust evidence/executor implementation; and the locked V1
verification evidence reuse references at commit
`e5acb677da6621004d96f0ef353c58fe8d3acfbf`.

Known: the current executor can skip a process from `reuse: bool` without any
receipt validation, and diff/environment values are not independently checked.

Unknowns: repository receipt location, retention, profile allowlist, and
CLI/MCP cross-process lifecycle belong to the next integration Work Item. No
Unknown blocks the in-process safety boundary.

## Acceptance Criteria

1. A receipt binds passed result, node, output, timestamps, and every content,
   diff, environment, command, scope, governance, toolchain, policy, stage, and
   runner identity.
2. Only an exact, passed, unexpired, valid non-protected receipt is reused.
3. Missing/malformed/tampered/failed/future/wrong-node evidence is Unknown and
   executes; a current-binding mismatch or expiry is Stale and executes.
4. Actual program and arguments determine command identity.
5. Protected nodes always execute and `protectedNodesSkipped` remains zero.
6. A dependency rerun forces downstream execution.
7. Reused commands spawn no process; telemetry reports reuse and rerun states.
8. No production `reuse: bool` or `with_reuse(bool)` skip API remains.
9. This Work Item creates no repository `.ai/` state.
