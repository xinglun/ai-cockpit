# WI-27 — 実行可能な V1 Behavioral Oracle

## 意図と目標

offline corpus による V1 parity の自己宣言を、外部 V1 reference Runtime
から得る実行可能かつ commit 固定の behavioral evidence に置き換える。

## Scope と Out of Scope

Scope は test 専用 V1 adapter、Rust trust-boundary integration test、14 個の
canonical case、正確な conformance metadata/documentation、専用 CI Oracle
job。Out of Scope は V1 の Runtime/adopter repository へのコピー、V1 API
compatibility、製品 Runtime の Python/network 依存、self-governance cutover、
release publication、無関係な governance capability。

## Sources と Unknowns

Sources は user execution specification の section 22/24/25 と Gate B、V1
reference commit `e5acb677da6621004d96f0ef353c58fe8d3acfbf`、既存の
conformance manifest と 14 fixtures、WI-27 design document。

Known: 現在の test は Rust output と repository 内で作成した expected JSON
を比較し、V1 を実行しない。

Unknown: 実行した V1 semantics が既存 V2 expectation と矛盾するか。矛盾は
captured V1 output から調整されるまで RED のままにする。

## Acceptance Criteria

1. 14 case すべてを正確に固定した V1 commit で実行する。
2. 各 case で 7 canonical semantic fields を比較する。
3. Adapter は V2 expected JSON を読まない。
4. 誤った reference identity、dependency 不在、malformed output、semantic
   drift は fail closed する。
5. CI は external Oracle を実行し、通常の product/adopter 利用は V1、
   Python、network に依存しない。
6. 英中日の documentation が boundary を正確に説明する。
