# WI-34 — Installable Release と Homebrew Distribution Readiness

## 意図と目標

WI-24 の build evidence を、GitHub Release archive、Homebrew、manual install、
tag-pinned Cargo Git fallback に共通する deterministic で testable な installation
contract にする。Public release 済みとは主張しない。

## Scope and Out of Scope

Scope は strict release manifest/version binding、stable archive layout、macOS
ARM64/Intel Formula の deterministic generation、source/archive/checksum/SBOM/
provenance coherence、staged install/uninstall/upgrade tests、cross-repository
handoff、least-privilege release workflow design、英中日 installation docs。

Out of Scope は `cockpit.toml` の JSON 化、V1 install、Linuxbrew Formula、crates.io
publication、`xinglun/homebrew-tap` 作成、commit/push、hosted workflow dispatch、
tag/GitHub Release 作成、tap PR 作成/merge、repository attach、public install 済みという
claim。

## Sources and Unknowns

Sources は protected release execution が pending の implemented WI-24 と、required

workspace、承認済み release approach、Homebrew の tap/Formula/trust 公式文書、Cargo install 公式文書、
GitHub artifact-attestation/release-integrity/hosted-runner 公式文書。Full design は

Unknown: external tap ownership control、GitHub App installation、protected credential、

## Acceptance Criteria

1. tag/workspace/package/binary/commit/lockfile/archive/manifest identity を検証し、
   mismatch は fail closed。
2. 5 target archive は一つの stable layout、canonical manifest、checksum set を使う。
3. macOS ARM64/Intel Formula generation は strict/deterministic/complete で、exact HTTPS
   URL と SHA-256 を使う。
4. Manual dispatch は publish 不可。Tag publication は source/artifact/manifest/smoke/
   SBOM/provenance/release gate 全通過後のみ。
5. Cross-repository Formula delivery は identity-bound PR handoff とし、default token や
   default branch への direct push を使わない。
6. Public Release なしで current ARM64/Intel runner の Homebrew install/test/uninstall を
   行う hosted fixture job を完全定義する。実行と hosted receipt は WI-35 に属する。
7. Local archive/Cargo Git fixture と workflow policy test が fallback の
   configuration-complete を証明し、hosted Linux/Windows receipt は WI-35 に属する。
8. 三言語 docs は install、verify、upgrade、uninstall、rollback、manual archive、Cargo Git、
   MCP、install と attach の区別を網羅。
9. `curl | sh` primary installer、Linuxbrew/crates.io claim、mutable tag reuse、未検証 public
   install claim を追加しない。
10. Development repository に `.ai/` を作成しない。
