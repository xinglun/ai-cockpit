# WI-27 — Executable V1 Behavioral Oracle

## Intent and Goal

Replace the offline corpus's self-declared V1 parity claim with executable,
commit-locked behavioral evidence from the external V1 reference runtime.

## Scope and Out of Scope

In scope: a test-only V1 adapter, a Rust trust-boundary integration test, all
fourteen canonical cases, honest conformance metadata and documentation, and a
dedicated CI Oracle job.

Out of scope: copying V1 into the Rust runtime or adopter repositories, V1 API
compatibility, product runtime Python/network dependencies, self-governance
cutover, release publication, and unrelated governance capabilities.

## Acceptance Criteria

1. All fourteen cases execute against the exact locked V1 commit.
2. All seven canonical semantic fields are compared.
3. The adapter cannot read V2 expected JSON.
4. Wrong reference identity, unavailable dependencies, malformed output, and
   semantic drift fail closed.
5. CI runs the external Oracle while ordinary product/adopter use remains
   independent of V1, Python, and network access.
6. English, Chinese, and Japanese documentation describe the boundary honestly.
