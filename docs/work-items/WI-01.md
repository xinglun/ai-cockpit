# WI-01 — Repository Protocol v1

## Intent

Define the repository-owned storage protocol before implementing Rust adapters.

## Scope

- `.ai/` layout and artifact identities.
- Canonical digest and timestamp rules.
- Contract envelope and decision semantics.
- Protocol compatibility and migration boundary.
- Machine-readable v1 schema and three-language documentation.

## Out of Scope

- Filesystem implementation.
- Runtime serialization code.
- Protocol v2 migration.

## Sources

- V2 execution specification.
- WI-00 product boundary.
- V1 evidence and lifecycle semantics, used only as reference.

## Acceptance Criteria

- Every required `.ai/` artifact has an owner and identity rule.
- Runtime and protocol versions are independent.
- Historical evidence cannot be rewritten by compatibility inspection.
- Unsupported protocol majors fail closed.
- English, Chinese, and Japanese specifications are semantically equivalent.

## Verification

- JSON schema parses with a standards-compliant validator.
- Valid and invalid protocol examples are checked in conformance tests.
- `git diff --check` passes.
