# WI-15 — Lifecycle Write Boundary

## 意図

repository への書き込みを .ai の facts、evidence、decisions、knowledge に限定する。

## 受入れ

runtime source や installer file を repository にコピーしない。

## 証拠

attach/doctor/lifecycle テスト（fail-closed の authority default と close decision を含む）

## 結果

状態：**Implemented**。attach/doctor/lifecycle テストが薄い repository write、authority 欠落時の default、明示的な human close decision を検証する。
