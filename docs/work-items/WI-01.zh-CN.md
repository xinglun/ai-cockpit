# WI-01 — Repository Protocol v1

## Intent

在实现 Rust adapter 之前定义由 repository 持有的存储协议。

## Scope

- `.ai/` 布局与 artifact identity。
- canonical digest 与 timestamp 规则。
- Contract envelope 与 decision semantics。
- Protocol compatibility 与 migration boundary。
- machine-readable v1 schema 和三语文档。

## Out of Scope

- filesystem 实现。
- runtime serialization code。
- Protocol v2 migration。

## Sources

- V2 执行规格。
- WI-00 产品边界。
- V1 evidence/lifecycle 语义，仅作为参考。

## Acceptance Criteria

- 每个 `.ai/` artifact 有 owner 和 identity 规则。
- Runtime 与 protocol version 独立。
- compatibility inspection 不能重写历史 evidence。
- 不支持的 protocol major fail closed。
- 英文、中文、日文规格语义等价。

## Verification

- 使用标准 validator 解析 JSON schema。
- 在 conformance tests 中检查 valid/invalid protocol examples。
- `git diff --check` 通过。

## Outcome

已在提交 `5c19a0e` 实现并推送。Protocol JSON 和 corpus JSON 已成功解析，没有复制 V1 runtime code。
