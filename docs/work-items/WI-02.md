# WI-02 — V1 Conformance Corpus

## Intent

Capture V1 behavior as semantic fixtures without making V1 a V2 runtime dependency.

## Corpus contract

Each case contains an input situation and an expected semantic result. Results are
compared by Decision State, Blockers, Unknowns, Safe Actions, Required Checks,
Authority, and Outcome State. Strings, JSON field order, and Python module names
are not compared.

## Required cases

The initial manifest covers scope exceeded, unauthorized destructive change,
missing/stale/contradictory evidence, unsupported completion, repository prompt
injection, malicious deletion, missing authority, invalid archive, cross-WI
evidence, unknown provider result, test weakening, and coverage weakening.

The V1 reference commit is recorded in `tests/conformance/v1-reference.lock`.
The V2 release binary never invokes Python or downloads the V1 repository.

## Acceptance Criteria

- Every required negative case has a stable fixture.
- Expected results preserve fail-closed semantics.
- Oracle provenance and fixture generation instructions are recorded.
- English, Chinese, and Japanese corpus documentation is equivalent.
