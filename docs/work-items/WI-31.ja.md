# WI-31 — Executable Runtime Identity Binding

## 意図と目標

AI Cockpit runtime identity claim と verification evidence を version-label
placeholder ではなく exact executing binary に bind する。

## Scope と Out of Scope

Scope は invocation ごとの単一 RuntimeContext、streaming executable SHA-256、CLI
inspect/doctor/verify propagation、explicit MCP context injection、consumer-visible
identity test。

Out of Scope は repository attach、profile confirmation、commit/push、hosted CI、
release signing、package archive identity、evidence reuse（WI-32）。

## Sources と Unknowns

Sources は user-approved WI-31 design、execution specification section 5/8/13/18/26、
Repository Protocol v1、current CLI/MCP placeholder call site、locked V1 evidence
trust boundary。

Known: candidate binary file digest は output/evidence に現在書かれる literal
`ai-cockpit-0.1.0` digest と一致しない。

Unknown: final release artifact/signature identity は release boundary に残り、runtime
evidence の代替ではない。Local implementation を block する Unknown はない。

## Acceptance Criteria

1. Runtime version は package version 由来で protocol version は別 type のまま。
2. Runtime digest は exact executing file の SHA-256 と一致する。
3. CLI/MCP は invocation ごとに同じ immutable RuntimeContext を reuse する。
4. Inspect、doctor、CLI verification evidence、MCP initialize、MCP verification
   evidence は同じ supplied identity を公開する。
5. Executable discovery/read failure は fail closed。
6. Production source に version-string digest placeholder が残らない。
7. この WI は current repository に `.ai/` state を作らない。
