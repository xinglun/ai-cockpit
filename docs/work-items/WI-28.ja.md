# WI-28 — Snapshot-Derived Governance Signals

## 意図と目標

3 つの hard-coded safe governance input を削除し、1 つの immutable Snapshot
から repository input trust、test weakening、coverage weakening を導出する。

## Scope と Out of Scope

Scope は process-local bounded change facts、deterministic signal analysis、central
decision wiring、CLI/MCP/lifecycle regression、disclosure test。Out of Scope は
V1 copy、2 回目の Git scan、general semantic code analysis、external provider
evidence、evidence-class expansion、self-governance install、release、無関係な
Observer capability。

## Sources と Unknowns

Sources は user specification section 10/13/15/24/25、WI-27 executable Oracle、
現在の RepositorySnapshot と central decision adapter。

Known: adapter は 3 つの literal `false` を渡し、Snapshot に reusable change-line
facts がない。Unknown: design 外の language-specific weakening。unsupported
inspection は明示的 Unknown のままにする。

## Acceptance Criteria

1. 3 production governance inputs は Snapshot-derived である。
2. Decision ごとの Git observation は 1 回、Git call は 4 のままである。
3. Test deletion は Red、coverage lowering と prompt injection は Yellow。
4. Relevant uninspectable change は Unknown/Yellow。
5. CLI/MCP は raw source/diff text を serialize しない。
6. CLI、MCP、finish、archive、close は central result を共有する。
