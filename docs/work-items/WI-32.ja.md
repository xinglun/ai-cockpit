# WI-32 — Fail-Closed Evidence Reuse Planner

## 意図と目標

Caller-declared verification skip を composite receipt validation、dependency-aware
planning、observable bounded execution に置き換える。

## Scope と Out of Scope

Scope は content/diff/environment composite identity、content-addressed passed
receipt、Fresh/Stale/Unknown classification、actual command identity、protected-node
enforcement、dependency invalidation、execution metrics。

Out of Scope は receipt-file persistence、profile-driven CLI/MCP reuse、repository
attach、commit/push、hosted CI、release signing、publication。

## Sources と Unknowns

Sources は user-authorized WI-32 design、execution specification section 14、current
Rust evidence/executor implementation、locked commit
`e5acb677da6621004d96f0ef353c58fe8d3acfbf` の V1 verification evidence reuse
reference。

Known: current executor は receipt validation なしに `reuse: bool` だけで process を
skip でき、diff/environment value は個別検証されない。

Unknown: repository receipt location、retention、profile allowlist、CLI/MCP
cross-process lifecycle は次の integration WI に属する。In-process safety boundary
を block する Unknown はない。

## Acceptance Criteria

1. Receipt は passed result、node、output、timestamp と全 content、diff、environment、
   command、scope、governance、toolchain、policy、stage、runner identity を bind する。
2. Exact、passed、unexpired、valid、non-protected receipt だけを reuse する。
3. Missing/malformed/tampered/failed/future/wrong-node evidence は Unknown/Execute、
   current-binding mismatch または expiry は Stale/Execute。
4. Actual program と arguments が command identity を決める。
5. Protected node は常に execute し、`protectedNodesSkipped` は zero のまま。
6. Dependency rerun は downstream execution を強制する。
7. Reused command は process を spawn せず、telemetry は reuse/rerun state を示す。
8. Production に `reuse: bool` / `with_reuse(bool)` skip API を残さない。
9. この WI は repository `.ai/` state を作らない。
