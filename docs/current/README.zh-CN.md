# 当前读者路线

这是使用已发布 AI Cockpit Runtime 的默认路线。第一次使用时，按以下顺序阅读：

1. [快速开始](../getting-started/README.zh-CN.md)——安装、验证、attach 并连接 Agent。
2. [功能](../features/README.zh-CN.md)——了解每项能力及其边界。
3. [运维](../operations/README.zh-CN.md)——运行、验证、恢复、升级和验收 Release。
4. [参考](../reference/README.zh-CN.md)——查找精确命令、配置和输出。

要理解产品思想和所有权模型，请阅读[设计思想](../philosophy.zh-CN.md)与[架构](../architecture.zh-CN.md)。
[参考源对齐记录](../reference/reference-parity.zh-CN.md)面向维护者和审查者，是比较资料，
不是复制实现历史的指令。
