# Current reader route

公開済み AI Cockpit Runtime を使う人のための既定 route です。初めて利用する場合は、
次の順に読んでください。

1. [Getting started](../getting-started/README.ja.md) — install、verify、attach、calibration、adoption configuration、最初の Work Item。
2. [Features](../features/README.ja.md) — 各 capability と責任境界。
3. [Operations](../operations/README.ja.md) — 実行、verify、recovery、upgrade、Release acceptance。
4. [Reference](../reference/README.ja.md) — 正確な command、configuration、output。

製品の思想と ownership model は[設計思想](../philosophy.ja.md)と[アーキテクチャ](../architecture.ja.md)を
参照してください。[Reference source parity](../reference/reference-parity.ja.md) は maintainer/reviewer
向けの比較資料であり、実装履歴をコピーするための指示ではありません。

新しい adopter は feature overview の短縮 lifecycle を closure recipe として使わないでください。
Canonical walkthrough は resource finalization と visible Outcome を含む
[最初の Work Item](../getting-started/first-work-item.ja.md)です。
