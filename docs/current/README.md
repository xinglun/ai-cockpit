# Current reader route

This is the default route for a person using the published AI Cockpit Runtime.
Read the short route pages in order when you are new to the product:

1. [Getting started](../getting-started/README.md) — install, verify, attach, and connect an Agent.
2. [Features](../features/README.md) — understand what each capability does and where it stops.
3. [Operations](../operations/README.md) — run, verify, recover, upgrade, and accept a release.
4. [Reference](../reference/README.md) — look up exact commands, configuration, and output.

For the product rationale and ownership model, read [Design philosophy](../philosophy.md)
and [Architecture](../architecture.md). The [reference parity record](../reference/reference-parity.md)
is a maintainer/reviewer comparison, not an instruction to copy implementation history.
