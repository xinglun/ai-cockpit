# Human Benefit Report

The Human Benefit Report is the person-facing projection of a validated Task
Outcome. It answers what was completed, what was found, what stopped, what was
resolved, what risks remain, what is unknown, and what the safest next action is.

It is not a second authority source. Claims remain tied to the Task Outcome's
evidence references; an undeclared user benefit remains an explicit unknown.
The Runtime localizes generated labels but preserves Contract acceptance text.

Use `work-item outcome` or MCP `work_item_outcome` for the handoff. Use
`--json` when a machine needs the stable OutcomeV2 and its optional
`taskOutcomeReport` projection.
